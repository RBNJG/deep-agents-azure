## Migraciones y configuración necesaria

Sin migraciones de datos. `uv sync --locked` instala la venv. Copiar el ejemplo
de entorno solo si no existe configuración propia, o proporcionar `PAW_ENVIRONMENT_ID`.
Solo se admite perfil `local`. Puertos por defecto: API 8000, MCP 8001, worker 8002.

Se corrigió un problema observado de Python 3.12/Windows con locale cp1252:
una ruta UTF-8 con tilde en el `.pth` editable impedía importar desde otro directorio.
Hatch `dev-mode-exact` y `editables==0.5` en desarrollo conservan la ruta mediante
un importador. La wheel de producción no necesita ese importador.

La comprobación final se realizó tras la instalación de Docker Desktop por el
usuario, con su ejecutable bajo `%LOCALAPPDATA%/Programs/DockerDesktop/resources/bin`.
El PATH de la sesión de VS Code aún no lo incluía. Se inició Docker Desktop con
`docker desktop start` y se usó el contexto `desktop-linux`. Las operaciones Docker
requirieron ejecución fuera del sandbox. Solo se retiró el proyecto de verificación;
se conservaron las imágenes/caché locales y Docker Desktop quedó iniciado.

La descarga de paquetes públicos requirió permisos de red del entorno de ejecución.
No se guardaron credenciales. Pytest emite un aviso de deprecación de Starlette
por el adaptador `httpx` de TestClient; los 14 tests pasan. El build avisa de que
la caché local está bajo la raíz; la selección explícita de distribución limita
su contenido a fuentes y metadatos.

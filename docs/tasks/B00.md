# B00 — Fundación del repositorio y contratos

**Objetivo:** Dejar un repositorio ejecutable y un lenguaje común para todos los agentes.

**Dependencias de entrada:** ninguna. Comprobar sus handoffs y el código.

## Contexto para el agente

No hay código implementado en esta planificación. Importar este paquete y adaptar el esqueleto al repo real. Las APIs exactas de SDKs se fijan mediante una prueba pequeña; no construir todavía el proceso completo.

Leer siempre `docs/PROJECT_CONTEXT.md` y `docs/CONTRACTS.md`. Las rutas de esta ficha son propuestas del repositorio; B00 las establece.

**Zona de trabajo:** Raíz, docs/, packages/contracts/, apps/*, pyproject.toml, lockfile y tests/smoke/.

**Fuera de alcance:** Azure, base de datos de negocio completa, UI elaborada y agente de compras.

## Puerta de salida del bloque

Un checkout limpio instala versiones fijadas, arranca health endpoints y valida los contratos compartidos.

Revisar las cuatro entregas, integración y contratos modificados. Una dependencia externa pendiente se informa como tal; no se sustituye por un mock para declarar este bloque completo.
